# Mutation testing, batch 547

A re-score of `optimize/outbox.py`, which keeps Optimize results on this PC when the central lakehouse can't be reached, and sends them the next time Optimize writes there. It bounds what waits by count and age, waits longer after each failure, counts what it drops, and says each lakehouse's sync state. It was last scored in batch 84 at **98.6%** (kinds all, 70 mutants, no boundary mutants), with 1 equivalent mutant. Since batch 84's `main` e9097a765, four commits changed it: 266bade15 (product data check), ea26eab78 (ESI-105: sync states, which added `reason`, `syncing` and `sync_state`), 859a4a30a (Windows hardening) and c88e0c642 (a damaged entry is skipped or refused by name). None of them reads `docs/`, `examples/` or `app/`, so nothing was left out.
