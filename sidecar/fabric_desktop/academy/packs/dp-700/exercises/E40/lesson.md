# Eventstream, Spark Structured Streaming or KQL: choose the engine

Clickwell streams events from its web shop. One team wants no-code routing, one wants live interactive queries, and one writes PySpark.

## What you'll do

Choose between an eventstream, Spark Structured Streaming and an eventhouse queried with KQL for four streaming jobs, and say why.

## Notes

- Eventstreams ingest, transform and route events with no code, in a drag-and-drop editor.
- Eventhouses analyze data in motion, queried with KQL or T-SQL, within seconds of ingestion.
- Spark Structured Streaming writes streams to Delta tables with a checkpoint; a trigger interval makes fewer, larger writes.

## What this run proves

- You can pick the right tool or store for each scenario, with the reason and source shown afterwards.

## What it doesn't prove

- That you can build it in Fabric: nothing is set up or run here. Doing it on a real item is FABRIC VERIFIED work.
