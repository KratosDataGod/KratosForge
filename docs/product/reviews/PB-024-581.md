## Outcome

**Changes Required** (recommended).

Querying a Fabric Warehouse and a SQL analytics endpoint as the signed-in user, read-only unless a confirmed change is started, is built and well tested with a fake connection. Two things keep it from being accepted: the item names the **Fabric SQL database** and the code can't reach one (`warehouse.KINDS` is warehouse and endpoint only, and the host must be `*.datawarehouse.fabric.microsoft.com`); and the engine that every green build of main publishes to the Preview channel carries Microsoft's ODBC Driver 18, whose redistribution terms (end users agree to protective terms) aren't met: `docs/end-user-terms.md` is a draft "not in effect" that the app doesn't show. No live query was run from this container.

Recommended by: Engineering quality review. Decided by (product owner): Chris, "I approve all of these move these forward" on 2026-10-28 (project message cmsg_018T4o2pQdpbLBNhHpgVNNGpFeQHvbSrE9FwPZyTzr8ao4), on the acceptance batch: Narrowed to warehouses; Fabric SQL database moves to PB-114. Stays In review until the ODBC licence terms (finding 2) are settled.
