One module not scored before, run with `--kinds all`:
- The app's calls for the KratosForge Environment: status, discover, plan and create, adopt, connect, switch, disconnect, check, cost and upgrade, with each change run only from a preview kept on the engine under a single-use token that binds the whole request, after a confirm and, for a Prod workspace, its typed name (`controlplane_service.py`).

The run was at `main` a73ebb71 (2026-11-24), with `sidecar/tools/mutate.py` and the method of earlier batches (sample cap 150, seed 7, `--kinds all`), on DuckDB 1.5.6. The per-mutant timeout was raised from 120 to 600 seconds by a wrapper that sets `mutate.TIMEOUT`, with the tool unchanged, because other runs shared the machine; no mutant's run timed out. Each pytest session got a fresh temporary folder, so a mutant can't leave one that breaks later runs. Each test set was run with `-x`. Test files were given as paths relative to `sidecar/`, and they first passed once on the unmutated copy. None of them reads `docs/`, `examples/` or `app/`, so nothing was left out for that reason. The module has 199 mutants, so a sample of 150 was run. `main` hasn't changed this module since.

The test set was test_controlplane_service and test_controlplane_hardening.

Before the "after" run, the new tests passed in a copy of `sidecar/` on its own and against the module as `ast.unparse` writes it. They also pass on DuckDB 2.0.0. Nothing in them reaches Fabric: they use test_controlplane_service's fixture, with a fake Fabric and lakehouses in folders. A clock stands in for `time.monotonic` where a preview's age matters. The first "after" run left one survivor that a test could reach after all; it got a test and was run again, and the table counts that second run.

### What the survivors were, and the tests that now kill them

- **controlplane_service.py**:
  - A preview lasts 900 seconds to the second: it can be checked and taken at 900 and is expired at 901. A preview exactly 900 seconds old isn't cleared away when another is kept. The existing tests read the limits from the module's own constants, so a changed constant passed them.
  - A preview that expires between its check and its use runs nothing.
  - 20 previews are kept, and the 21st drops the oldest. A preview token is 32 characters.
  - A preview's digest reads keys in any order.
  - A plan request field of 256 characters is taken and 257 isn't. Unknown fields are named in at most 200 characters.
  - A workspace that isn't Prod needs no typed name, also when the request names it by id.
  - Adopt needs a central lakehouse first.
  - Cost covers 30 days by default, takes 1 and 366, and quotes at most 20 characters of a wrong value.
  - An upgrade plan needs the manifest still in its lakehouse. An upgrade whose manifest went away runs nothing. An upgrade with nothing left to do says so.
  - A check whose tables can't be read is connected and offline, with the error.
  - A connection saved without its schemas flag reads a schema-enabled lakehouse when adopted.
  - → `test_controlplane_service_mutation_b.py`.
