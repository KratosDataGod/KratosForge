# PB-077: User and agent docs match the code

**State:** Proposed. Not approved for implementation. **Priority:** P2.
**Owner when approved:** Master product (unassigned).

## 1. PR title and ID

`Correct user, agent and plan docs that disagree with the code` (PB-077)

## 2. Business problem

People follow the docs. Where docs describe behavior the code doesn't have, users lose trust and
contributors build on wrong assumptions.

## 3. Current verified behavior

Mismatches found in this assessment (code at `b7b04cc`):

| Doc | Says | Code |
| --- | --- | --- |
| `docs/user-guide.md` line 349 (Report a problem) | adds your tenant id | `redact.py` removes GUIDs including the tenant id |
| `docs/agent.md` | workload views read agent status records | only `workloads/evaluate.py` reads them |
| `docs/enterprise-roadmap.md` | the pipeline mailbox is not built; names a `results/` folder | `mailbox.py` is built and uses `status/` |
| `docs/workloads/plan.md` §2.1 | incidents are a `meta.incidents` Delta table | `workloads/incidents.py` keeps a JSON document |
| `docs/workloads/continuation.md` | PR #79 open | merged |
| `docs/troubleshooting.md` line 45 | Fabric's catalog is embedded on the same page as Endorsed items | no embedded catalog on that page |
