# Dataflow Gen2, notebook or T-SQL: choose the transformation tool

Northgate's analysts, data engineers and SQL developers all transform data. Each team's job and skills point to a different tool.

## What you'll do

Choose between Dataflow Gen2, a Spark notebook and T-SQL in a warehouse for four transformation jobs, and say why.

## Notes

- Dataflow Gen2: Power Query (M), no code or low code, for wrangling and profiling; business analysts use it too.
- Spark notebooks: code (Python, Scala, Spark SQL, R) for complex transformation at any volume.
- T-SQL transformation and loading (INSERT, CREATE TABLE AS SELECT, COPY INTO) runs in a warehouse; a lakehouse's SQL analytics endpoint has no DML.

## What this run proves

- You can pick the right tool or store for each scenario, with the reason and source shown afterwards.

## What it doesn't prove

- That you can build it in Fabric: nothing is set up or run here. Doing it on a real item is FABRIC VERIFIED work.
